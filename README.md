# 🍀 오늘의 행운 뽑기

버튼을 누르면 오늘의 운세와 행운의 색, 행운의 숫자를 랜덤으로 보여 주는 웹 프로젝트입니다. HTML, CSS, JavaScript의 기본 문법과 화면 제어를 연습하기 위해 만들었습니다.

## 🔗 바로가기

**[오늘의 행운 뽑기 실행하기](https://baehyemin9.github.io/lucky-draw/)**

실행 주소: https://baehyemin9.github.io/lucky-draw/

## 주요 기능

- 5가지 운세 중 하나를 무작위로 선택합니다.
- 운세에 맞는 이모지와 설명을 표시합니다.
- 행운의 색과 1~45 사이의 행운의 숫자를 보여 줍니다.
- 운세에 따라 페이지와 카드의 배경색이 부드럽게 바뀝니다.
- 현재 페이지에서 뽑은 횟수를 표시합니다.
- 화면 너비에 맞춰 카드 크기가 조절됩니다.

## 사용 방법

1. 위의 실행 링크를 엽니다.
2. **🔮운세 뽑기** 버튼을 누릅니다.
3. 운세, 색, 숫자를 확인합니다. 버튼을 다시 누르면 새 결과가 나옵니다.

새로고침하면 뽑은 횟수는 0으로 초기화됩니다. 운세와 숫자는 재미를 위한 무작위 결과입니다.

## 사용 기술과 파일 역할

| 파일 | 역할 |
| --- | --- |
| index.html | 운세 카드, 색과 숫자, 버튼 등 화면 구조 |
| css/style.css | 카드 디자인, 색상, 배치와 배경 전환 효과 |
| js/script.js | 랜덤 추첨, 조건문에 따른 운세 선택, 화면 갱신과 횟수 계산 |

JavaScript의 querySelector, Math.random, Math.floor, if/else, 함수, textContent, addEventListener를 활용했습니다.

## 내 컴퓨터에서 실행

저장소를 내려받아 압축을 풀고 index.html을 브라우저에서 열면 됩니다. css와 js 폴더는 같은 위치에 유지해 주세요. 별도 서버나 패키지 설치는 필요하지 않습니다.
